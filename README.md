# CVAT+

A custom fork of [CVAT: Computer Vision Annotation Tool](https://github.com/cvat-ai/cvat),
based on upstream v2.84.0, with additional UI features:

- **Grid view for the tasks page**, with an updated task status indicator
- **Task thumbnail frames preview** in the task list
- **Hyperlinks on the task image and title** for quicker task navigation

For everything else — the original project, documentation, installation
instructions, and releases — see the
[CVAT repository on GitHub](https://github.com/cvat-ai/cvat).
